# notes-manager
A responsive notes management application built using React and Tailwind CSS that allows users to create and delete notes through a clean and interactive interface.

---

## Features

- Add Notes
- Delete Notes
- Responsive UI
- Interactive Design
- Dynamic Rendering using React

---

## Tech Stack

- React
- Tailwind CSS
- JavaScript
- HTML
- CSS

---

## Installation

1. Clone the repository

git clone <your-repo-link>

2. Navigate into project folder

cd smart-notes

3. Install dependencies

npm install

4. Start development server

npm run dev
